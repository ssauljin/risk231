Why R for Statistical Modeling?

R is a statistical programming language! Statistics are built-in from its core, which is why it’s really good for predictive modeling including but not limited to actuarial applications.

For example: If you want to get random samples from a particular distribution, there are functions in R to do so:

Normal Distribution: rnorm()
Uniform Distribution: runif()
Poisson Distribution: rpois()
Gamma Distribution: rgamma()
Binomial Distribution: rbinom()

A Simplified Walk-Through of Modeling in R

For modeling, since it’s impossible to have all of the data from the full real population, we need to work with the data we have. Thus, we want to create a proxy situation for the full, real data. We do this by splitting our data into two datasets: Training and Test. We will use the Training data to adjust and build our model (i.e. “train” our model) how to interpret, and thus predict, the behavior of the data. We then do a final test of how well this model might work with the real population by using a proxy dataset, our Test data.

The general rule of thumb on how to split the data is a random 80/20 split, 80% going to the Training dataset and 20% going to the Test.

set.seed(0)
randrows <- sample(1:nrow(df), 0.8 * nrow(df))
df_train <- df[randrows, ]
df_test <- df[-randrows, ]

Simulation of a 95% Confidence Interval

P(xbar - 1.96 * sigma / sqrt(n) <= mu <= xbar + 1.96 * sigma) = 0.95

Interpretation: If we repeat the CI construction process for a large number of independent random samples, then we should expect that 95% of those realized CIs will include the true mean.

# Initialization
n <- 100          # size of random sample we are goint to draw in each simulation
n_sim <- 1000000     # number of simulation times
mu <- 5           # true mean for the normal dist
sigma <- 2        # true sd for the normal dist
count <- rep(NA, n_sim) # create an empty vector to store our result

# Simulation
set.seed(0)

for (i in 1:n_sim) {
  # draw a random sample with size n from the N(5, 2^2)
  x <- rnorm(n, mu, sigma)
  # RHS is a logical test to test whether the true mean is contained in the realized CI constructed
  #   by the random sample above or not, if yes, then assign TRUE to count[i], and vice versa.
  count[i] <- (abs(mean(x) - mu) <= qnorm(0.975) * sigma / sqrt(n)) 
}

# Finally, we can calculate the average of count to see appox percentage of 
# how many true means fall into the realized CI in this 1000 times simulations
mean(count)
## [1] 0.949876
